## 🚀 Features

- **Industrial & Gen-Z Aesthetic:** Dark mode architecture with neon acid-lime accents (`#CCFF00`), clean typography (`Cabinet Grotesk` & `Satoshi`), and glassmorphism navbar.
- **Dynamic Pitch Showcase:** Highlights FIFA-grade Monofilament synthetic turf and Interlocking Vinyl courts with transparent pricing.
- **Dual Booking Flow:**
  - **Booking Saja:** Standard WhatsApp booking for pay-at-venue / DP arrangements.
  - **Booking & QRIS:** Interactive modal displaying instant QR payment options with auto-calculated total hours and rates.
- **Mobile Responsive:** Fully optimized layout for seamless booking across smartphones, tablets, and desktops.

---

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** Tailwind CSS (via CDN with custom config)
- **Icons & Fonts:** FontAwesome 6, Fontshare (Cabinet Grotesk & Satoshi)
- **Scripting:** Vanilla JavaScript (DOM manipulation & dynamic WhatsApp URL scheme generator)

---

## 🏁 Quick Start

1. Clone or download this repository.
2. Open `index.html` directly in any modern browser, or run via a local server (e.g., Live Server in VS Code).
3. Update the WhatsApp number placeholder (`6281234567890`) in the script section with your actual business number.
